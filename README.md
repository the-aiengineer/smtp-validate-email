# SMTP Validate Email

Legacy PHP utility for validating email addresses through SMTP.

## What it demonstrates

This project is an earlier example of backend development involving:

- SMTP communication
- MX record discovery
- Email address verification
- Catch-all detection
- Batch processing
- Connection timeouts
- Logging and debugging
